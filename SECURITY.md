## Reporting a Vulnerability

We take the security of this project seriously. If you discover any security vulnerabilities, please do not report them through public GitHub issues. Instead, follow our disclosure process below:

### How to Report
Please send an email detailing the vulnerability to **security@yourdomain.com** (replace with your secure contact email). 

To help us triage the issue quickly, please include:
* A detailed **description** of the vulnerability.
* Clear **steps to reproduce** the issue (or a proof-of-concept script/exploit).
* The potential **impact** of the vulnerability.

### What to Expect
* **Acknowledgment:** You can expect an initial response acknowledging your report within **48 hours**.
* **Updates:** We will provide status updates at least once every **3-5 business days** while analyzing and fixing the issue.
* **Resolution:** If accepted, a security patch will be built and released. You will receive credit in our release notes if desired. If declined, we will provide a clear explanation of why it was determined not to be a vulnerability.
